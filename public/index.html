Verify a Git Commit

Add these keys as trusted signers, then verify:

echo "drbh@dholtz.com $(curl -s https://dholtz.com/.well-known/ssh-keys | head -1)" >> ~/.ssh/allowed_signers
echo "drbh@dholtz.com $(curl -s https://dholtz.com/.well-known/ssh-keys | tail -1)" >> ~/.ssh/allowed_signers
git config gpg.ssh.allowedSignersFile ~/.ssh/allowed_signers
git log --show-signature
